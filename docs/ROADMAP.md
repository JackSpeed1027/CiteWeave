# 开发路线

1. **首次验收**。用样本文件证明浏览器、Spring Boot 与 PostgreSQL 连通，验证错误处理和后端重启后的读取。交付后等待验收。
2. **完成 MVP**。为摘要和问答接入配置了真实凭据的 OpenAI-compatible 接口，限制上下文，保存笔记和收藏夹，执行完整验收。
3. **导入扩展**。逐步加入网页、原文件归档和可定位引用。
4. **后端可靠性**。按长任务的需求增加队列、租约、幂等与索引版本，并测试重复投递、并发及执行中断。
5. **Agent 和评测**。按需引入 Python 和 LangGraph，验证证据检索、预算和恢复。所有指标记录实际实验条件与结果。

目标交付日期为 2027 年 1 月 15 日。每一步以可运行、可复验的结果推进。
