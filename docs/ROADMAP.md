# CiteWeave 开发路线

计划窗口为 2026-11-19 至 2027-01-15。按每周 5 个有效日、每天约 5 小时预算，首周和最终周也保留机动时间。下表估时含调试、教学和自测。没有可验证的访问权限、模型额度或部署环境时，使用对应降级路径，释放预算给验收。

## 优先级与取舍

- **P0**。现有资料闭环、带时间戳字幕、独立 Bilibili 预览与分 P 确认、可授权字幕或用户字幕降级、本地视频与字幕、真实单资料摘要和问答、笔记收藏与导出、可追溯引用、可重试的任务和一条可演示的多步分析流程。
- **P1**。CPU ASR 与中间产物复用、RabbitMQ Outbox/Confirm/ACK 与 Lease/CAS 故障实验、全文和向量检索、索引版本发布、LangGraph Checkpoint。优先保住一条端到端的可复现链路，指标等实验完成再写。
- **P2**。弹幕深度分析、画面理解、GPU 优化、Reranker、Redis、MinIO、全局标签与复杂权限。只有出现明确的性能或跨节点存储需求再引入基础设施。
