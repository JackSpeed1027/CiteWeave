# 测试计划

| 阶段 | 执行与观察 | 验收 |
| --- | --- | --- |
| 基线 | Maven package 和 Vite build | 单元测试、类型检查和构建成功 |
| 字幕 | SRT/VTT、BOM、CRLF、重叠、错误时间、真实 HTTP 和 PostgreSQL | 201 后原文可读，时间轴为整数毫秒；坏上传 422 且记录数未变化，非字幕 404 |
| 视频 Adapter | 多 P、失败、重定向、限流，实测可处理的公开素材 | CID 与选择一致，明确状态，字幕可降级 |
| 文件和任务 | 不合法视频、重复投递、超时与并发抢占 | 仅发布一致的产物，重试可恢复 |
| RAG/Agent | 固定证据集与模型；版本切换和 Checkpoint | 引用能定位来源，任务中断可恢复 |
| 发布 | Windows 和 Linux 回归、清洁环境部署、用户验收 | 端到端演示可重放，限制和真实数据有记录 |
