# 产品需求

CiteWeave 将文档、网页和字幕汇集到同一工作空间，让用户阅读原始内容，并逐步支持带有出处的 AI 分析。

## 首次验收

工作台展示真实资料统计和近期导入。资料库按标题或文件名搜索，可按格式筛选。导入页接受单个 PDF、TXT、Markdown、SRT 或 VTT 文件，以及粘贴的正文。资料工作区显示保存的正文、资料类型、导入日期和字符数。错误时提供重试入口或修正建议。

## 完整 MVP

用户能从正式工作区打开字幕或文档，生成带出处的摘要与问答，点击引用核对原句，再将结论保存为笔记并导出 Markdown。刷新页面后能查看原任务、笔记和引用。生成失败保留原资料、已保存笔记和本次问题，显示失败原因、是否可重试及下一步操作。资料中找不到答案时，页面明确提示证据不足。网页提取按后续扩展排期。

当前可从已有研究结果保存笔记，手动编辑标题与 Markdown，从笔记列表重开并导出。引用保留原研究的原句和位置。笔记预览、自动保存和版本恢复按原型路线后续安排。

## 研究会话体验（成品验收目标）

同一会话能理解“展开上次回答的第二点”，刷新后回到原问题、进度和引用。用户能将结论或未决问题确认为个人工作区记忆，在新会话续研，查看来源、更正或撤销。长任务自动整理较早上下文，用户仍能查看原始轮次、回读授权证据和取消当前运行。实现与验证见[研究 Agent 规划](../planning/AGENT_MEMORY.md)。

## 视频产品路线

Bilibili 是主要视频来源。Java 已提供输入规范化、公开元数据和分 P 预览 API，另有字幕解析 API。正式页面的选 P、确认入库与工作区联动按[正式开发计划](../planning/IMPLEMENTATION_PLAN.md)验收。已有字幕优先，平台访问失败时可上传字幕。规划中的本地视频入口允许先关联字幕，无字幕时再对授权素材做 ASR。两种来源共享字幕时间轴和证据引用。
