# 架构决策

- **本地 Monorepo**。前后端、迁移、基础设施和验收样本可在同一份版本中同步评审。前后端分别构建，通过 Vite 代理联调。
- **JdbcClient + Flyway**。资料模型仅需三个参数化 SQL 操作，Spring JDBC 的依赖和配置较少。表结构变更走版本化迁移，复杂映射出现后再评估 MyBatis。
- **同步解析、一次写入**。约束上传体积、PDF 页数和提取文本长度。解析失败时数据库没有写入。并发插入使用数据库标识生成，重复提交目前会得到独立资料。
- **PDFBox 与 UTF-8 文本处理**。支持 PDF 文本层并保留文本和字幕布局。异常文件和不可提取内容返回明确错误。
- **React + CSS 设计系统**。用 CSS 变量管理色彩及控件，Lucide 提供一致的图标。四页共享布局、按钮、状态和列表组件，后续可按复杂度增加组件依赖。
