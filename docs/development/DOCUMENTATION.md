# 项目文档交付清单

## 最终验收统一交付的图

项目最终验收时，以实际交付版本为准一次性绘制成品图，统一存放在架构目录，由[架构文档](../architecture/ARCHITECTURE.md)链接。开发阶段无需绘制或维护中间版本。已保存的现状图和目标图可作为阶段记录查阅。

| 成品图 | 包含内容 |
| --- | --- |
| 架构图 | 服务、调用方向、运行依赖与存储归属 |
| 业务时序图 | 关键链路的参与者、调用顺序、事务或授权边界、失败出口 |
| 数据模型图（ERD） | 基于实际 Flyway 版本的实体、主外键、数据归属和生命周期 |
| 任务状态图 | 基于实际状态转换和测试的合法动作、超时、重试、恢复、取消与终态 |

## 随变更交付的资料

实现改变时更新受影响的资料，并在交付记录中链接契约或实测证据。涉及计划中的能力时，标明设计目标和验收状态。

| 长期交付物 | 放在哪里 | 什么时候更新 |
| --- | --- | --- |
| API 接口文档 | [接口文档](API_REFERENCE.md)及[通用契约](API_CONTRACT.md) | 每次新增、修改或废弃接口随实现交付，补使用方、请求、成功和错误示例、幂等或重试约定、兼容性及测试链接 |
| 架构决策与授权边界 | [架构决策](../architecture/DECISIONS.md) | 引入重要依赖、调整数据归属、权限、重试策略或公共契约时，记下选型理由与代价 |
| 部署、排障与恢复 | [本机环境](DEVELOPMENT.md)及后续实际部署指南 | 启动命令、环境变量、端口、迁移或备份恢复步骤变动时。涉及授权、存量数据和恢复演练时写明验证范围 |
| 测试、实验与评测证据 | [测试计划](../quality/TEST_PLAN.md)、[评测](../quality/BENCHMARK.md)、[小实验](../learning/LABS.md) | 核心功能交付时记录命令、样例、代码版本、实际结果与已知限制。性能指标随可复现结果更新 |
| 产品操作与进度 | [产品范围](../product/PRODUCT.md)、[开发日志](../planning/DEVLOG.md)及对应使用手册 | 路线和交互改变时更新用户操作。重要里程碑记录交付、阻塞与验收状态 |

接口规范在服务提供 OpenAPI 后与实际生成结果核对。Markdown 保留场景、真实样例、兼容性和跨服务导航。
