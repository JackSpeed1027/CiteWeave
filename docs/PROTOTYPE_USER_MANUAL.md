# CiteWeave 原型使用手册

本手册供 Windows 桌面端体验与验收使用。CiteWeave 原型可以完成「导入资料 → 整理分类 → 研究与引用 → 编辑成果 → 保存或导出」的操作。原型顶部的「演示模式」说明资料正文、摘要、转录、Agent 输出及模拟连接均使用样例。资料归类、对话历史、文档编辑、任务状态和文件下载在当前浏览器中实际运行。

## 1. 启动与快速体验

在项目根目录打开 PowerShell。

```powershell
Set-Location web
npm.cmd ci
npm.cmd run prototype
```

打开 [CiteWeave 原型](http://127.0.0.1:5175/prototype.html)。Node.js 和 npm 用于启动，模型密钥、GitHub Token、Java、PostgreSQL 与 Docker 均无需配置。根路径是既有资料工作台，原型入口带有 `/prototype.html`。

首次进入可看到 RabbitMQ 视频、读书摘记、工程文章、LangGraph 阅读笔记和一段本地视频演示。建议先打开「收藏夹 → 后端工程 → 在 Agent 中研究」，提出「对比各资料中的故障恢复思路」。打开一条引用，确认其落到相应片段，随后返回对话，生成文档并导出 Markdown。

原型数据绑定当前浏览器配置与站点地址。刷新同一地址会继续读取资料、分类、对话、笔记、任务及演示配置。换端口、换浏览器、使用无痕窗口或清除站点数据会改变可访问的数据范围。

## 2. 首页、导航与全局搜索

**场景**。继续昨天的研究，重开资料或笔记，找到正在执行的导入任务。

- **首页**显示最近的资料、笔记、活跃任务和部分常用分类及对话。点击一行进入详情。快速入口分别指向 Bilibili、本地视频、文档和网页导入。通过「打开 Agent」开始研究。
- **全局搜索**可点侧栏搜索框，也可按 `Ctrl+K`。例如输入 `RabbitMQ`，从结果选择待看的资料或笔记。按 Esc 可退出对话框。
- **任务快捷入口**可从顶部活动图标或首页进入。窄屏通过顶部菜单展开导航。

**边界**。全局搜索按资料标题及来源说明、笔记标题匹配。全文、字幕正文和外部站点的内容搜索属于正式项目范围。首页只显示一部分近期项，完整列表在各功能页。

## 3. 导入中心

各导入入口的通用步骤是「选择类型 → 准备输入 → 确认 → 查看任务」。链接入口先做格式校验，再呈现演示预览。文件入口读取浏览器选择的文件名、大小等信息。任务完成后点「打开资料工作区」。

### Bilibili 视频与分 P

**场景与案例**。想把课程中的某一节加入学习专题。点「填入示例链接 → 预览样例」，查看封面、标题、UP 主、时长与分 P。选择 P3「幂等消费的工程实践」并开始导入。工作区标题保留分 P。

**无字幕演练**。同一预览中选择 P2，保持「优先使用已有字幕」，也不附加字幕。点「登记待补充任务」，再从任务详情点「返回导入补充字幕」。附加 SRT/VTT，或选择「模拟 ASR 转录」，点「继续原任务」。任务详情沿用原任务编号。

**边界**。支持示例形式的 Bilibili 视频页、BV/AV 编号及 b23.tv 短链接。预览的封面、时长、分 P 与字幕可用性来自样例，用户输入的链接会作为来源入口保留。链接识别不代表已经访问 Bilibili，视频权限、短链解析、字幕提取与真实播放仍需正式集成。

### 本地视频

**场景与案例**。导入课程录屏。选「本地视频」，拖放或选择一个 MP4，也可选择 MOV、MKV 或 WebM。观察文件名、大小和可读取的时长。附加仓库中的 `sample-data/research-captions.srt`，点「开始导入」。也可以选择「模拟 ASR 转录」来体验无字幕流程。

**失败演练**。开始前勾选「演练一次处理失败与重试」。等任务出现演示故障后点「重新执行」，观察上传、音频、字幕、理解、摘要、索引各阶段推进。

**边界**。视频入口接受一个文件，单文件须非空并在 500 MB 内。附加字幕支持非空 SRT/VTT，最大 10 MB。时长依赖浏览器对实际容器与编码的支持。文件字节留在本机，原型记录元数据并展示样例内容，字幕与摘要不会按上传文件重新生成。

### 文档

**场景与案例**。把技术提案和阅读笔记一起归档。选「文档」，将 PDF 和 Markdown 一起拖入，也可在文件选择器中多选。核对列表中的名称、格式与大小，移除选错的文件，再提交。每份文档都有独立任务。

**边界**。入口接受 PDF、DOCX、TXT、MD、Markdown，文件须非空且每个不超过 500 MB。正文和页码使用演示文本。真实 PDF 文本提取存在于仓库的独立资料工作台，原型此入口与它独立运行。

### 网页与 GitHub

**场景与案例**。把一篇工程文章、一个开源仓库加入同一研究。选「网页」粘贴 HTTP(S) 地址，或选「GitHub」粘贴 `https://github.com/langchain-ai/langgraph`。预览样例后导入，工作区的「原始来源」可回到所填链接。想演练网页不可用，可试 `https://missing.example/article`，再按提示改走文档上传。

**边界**。网页正文、标题、摘要及 GitHub 阅读内容来自样例，GitHub 文件路径和行号对应原型内参考位置。原型接收公开格式的仓库 URL，私人仓库读取、OAuth、README 实际提取与同步属于后续能力。

## 4. 任务中心

**场景**。同时导入多份材料时回看队列，定位其中的异常任务。

1. 从侧栏打开「任务中心」，切换全部、待处理与进行中、已完成、失败或已取消。
2. 点击任务打开详情抽屉，查看百分比、已完成的阶段和当前阶段。
3. 进行中的任务可取消。失败或已取消时可重新执行。需要字幕的任务按详情提示继续原任务。已完成时打开资料工作区。

**案例**。演练一次本地视频失败，然后重新执行到 100%。刷新页面可看到已保存的任务状态。

**边界**。进度按原型时序推进，展示错误、恢复和取消的产品交互。耗时不代表真实上传速度、处理成本或后台性能，状态也不能作为生产任务可靠性的证据。

## 5. 知识库

**场景**。从不同类型与专题中找到需要阅读或归档的资料。

| 功能 | 示例操作 | 边界 |
| --- | --- | --- |
| 搜索和筛选 | 搜索 RabbitMQ，再选 Bilibili 类型、Java 标签或后端工程分类 | 查询匹配标题、来源说明、标签。知识库分类筛选只看直接归属的资料 |
| 列表、网格与排序 | 切换右侧视图按钮，按最早或最新导入排序 | 视图影响展示，数据和导入状态一致 |
| 收藏 | 点资料行的星标，再点「只看收藏」 | 星标与归属分类是两个独立属性 |
| 批量归档 | 勾选视频和 PDF，点「移动」，选后端工程。点「添加标签」加上「复习」 | 每份资料有一个归属分类，可有多个标签。批量操作作用于当前筛选结果中的已选项 |
| 重新处理 | 勾选需要演练的资料，点「重新处理」，到任务中心查看 | 执行演示处理 |
| 删除 | 仅对准备移除的演示条目勾选，点「删除 → 确认移除」 | 原型资料及关联任务会移除，笔记保留，原型内引用可能失效，原始上传文件与远端内容独立 |

## 6. 收藏夹、文件夹与标签

**场景与案例**。建立「可靠消息」收藏夹，在它下面创建「故障恢复」文件夹。选中子文件夹，点「添加已有资料」，把 Worker 故障演示移入。以后分类主题变化时点「重命名」，资料归属和子文件夹保留。

- **创建收藏夹**用于常用的顶层研究主题。用「新建文件夹」和「上级分类」形成层级。点击分类树查看直接归属的内容。
- **标签管理**可创建主题标签或移除标签。确认移除会从资料和笔记移去该标签。标签可以横跨多个收藏夹。
- **在 Agent 中研究**从当前分类选取处理完成的资料，并纳入子文件夹。例子是从「可靠消息」一次打开主目录的视频和「故障恢复」里的录屏。进入 Agent 后仍可调整上下文。

**边界**。收藏夹用于个人分类。团队共享、成员权限、分类同步和规则自动归档属于后续范围。当前可用快捷移动与批量移动，整理大型目录时用知识库筛选后批量操作。

## 7. 资料工作区与引用

**场景与案例**。打开 RabbitMQ 资料，点击「消费者幂等」章节，查看字幕与时间点。点击摘要中的引用，观察选中片段。随后在右栏切换「资料问答」，填写「何时会发生重投递」，发送到 Agent。

- **视频**提供章节、演示时间轴、播放或暂停控制、字幕片段、摘要、知识点与原始来源入口。时间轴可模拟定位。
- **文档和网页**可以用目录、页码或段落标签定位演示片段，查看摘要并继续提问。
- **GitHub**可以查看样例文件和行号标记。原始来源入口使用导入时的 URL。
- **生成学习笔记**从当前资料生成一篇可编辑 Markdown，保留所关联的资料。可直接收藏原资料或调整分类。

**边界**。引用指向原型中可查看的演示片段。时间轴、页码、段落及行号没有与外部内容逐项核对。来源链接可供回看入口，不能作为外部文本已被核验的凭证。

## 8. Agent 工作台

**场景与案例**。选 RabbitMQ 视频和读书摘记，问「比较两份资料如何处理重复投递，整理一份技术报告」。观察执行过程中的搜索、读片段、对照、生成，然后点引用检查证据。点击「生成文档」继续编辑。

1. 从侧栏新建对话，也可以打开历史对话，或从资料、收藏夹进入研究。
2. 点「选择资料」，用标题、来源或标签搜索，可按分类筛选。点击「选中全部结果」添加当前可见资料。切换筛选会保留已选项，「清空选择」可重新选取。
3. 每次研究使用不超过 **6 份已完成资料**。超过时请取消部分勾选。按 Enter 发送，Shift+Enter 换行，也可点快捷示例填入问题。
4. 运行时可停止。停止后可重试，完成后可以复制回答或重新生成。历史对话保存在当前浏览器。
5. 试问「整理一份学习笔记并保存到 Obsidian」。回答后点「预览并保存到 Obsidian」，依次确认文档、目标路径与内容。GitHub 和本地目录同样支持对应表述。

**边界**。回复由选择的样例证据和预设流程组成，支持体验工具轨迹、取消、结果和保存确认。真实语义检索、模型推理、联网、模型费用和后台执行能力属于正式系统。生成文件仍需要页面确认后才进入保存流程。

## 9. 笔记和文档版本

**场景与案例**。把 Agent 报告改成自己的知识笔记。打开笔记，将正文补成「决策、理由、验证计划」三段。点「属性」重命名，添加 Java 标签并选专题。回到列表按分类和标签查找，再用关键词把范围缩小。

- **新建及编辑**。点「新建笔记」或从资料与 Agent 生成。支持双栏、只编辑和只预览。可输入 Markdown 标题、列表、表格、代码块、引用及图片语法，预览随编辑更新。
- **自动保存**。修改正文后可观察「正在自动保存」与「已自动保存」。刷新同一浏览器地址可恢复正文。在重要修改前可打开「版本 → 保存当前版本」。
- **恢复**。在版本记录中选旧版本并预览，确认恢复后会另外保留恢复前的当前版本。
- **复用与分类**。「保存副本」新建独立文件。「另存为」打开目的地抽屉。「属性」修改名称、标签和归属分类。「笔记与文档」按标题或标签词搜索，可组合分类与标签筛选，父分类包含子文件夹。无结果时可「清除筛选」。

**边界**。版本由用户手动创建检查点，自动保存更新当前稿。多人协作、完整差异合并、跨设备同步及附件托管属于后续范围。外部图片预览依赖图片地址可达，便携文档建议优先使用可访问的素材地址。

## 10. 导出与统一保存

**场景**。把学习笔记交给同事、存到知识库或留在本机。

| 格式 | 使用案例 | 特性 |
| --- | --- | --- |
| Markdown | 在 GitHub 或 Obsidian 继续编辑 | 保留 Markdown 文本和原型来源说明 |
| TXT | 在普通文本工具阅读 | 简化格式，适合快速阅读 |
| JSON | 查看结构或交给其他工具处理 | 包含标题、内容及来源标识 |
| DOCX | 交给 Word 用户二次编辑 | 生成可下载文档，适合标题和正文；复杂 Markdown 表格、图片与主题样式可能简化 |
| PDF | 生成便于阅读的固定版式 | 打开浏览器打印预览，手动选择「另存为 PDF」。指定目录的 PDF 保存使用模拟流程 |

**操作案例**。打开一篇笔记，点「导出」，选 Markdown 后下载。若要保留一份工作区副本，先点「保存副本」。需要指定保存目的地时点「保存到…」或「另存为」，检查文件名和相对路径，再点「检查路径并预览」。同路径已有记录时应核对现有内容与计划更新，再确认。

## 11. 三种目的地

### GitHub

**案例**。进入「外部集成 → GitHub → 设置演示连接」。选演示仓库 `research-reports`、分支 `drafts`、目录 `Research/Java`。点「测试连接」核查表单后保存。回到文档选择 GitHub，填写文件名和提交说明，预览后点「确认模拟提交」。对同路径重复操作，核对新旧内容后确认模拟更新。

**边界**。仓库、分支、权限说明、连接测试与提交回执均属于演示。GitHub 上的仓库不会出现该提交。配置只需原型字段，请勿填入 Token。

### Obsidian

**案例**。在外部集成设置 `Learning Vault`，默认目录写 `Java/RabbitMQ`。让 Agent 生成学习笔记并走保存流程，在预览中核对 YAML Frontmatter、标题、标签和引用说明。确认模拟保存后可在「保存历史」查看记录，也可直接下载 Markdown 后导入 Vault。

**边界**。演示配置只管理原型字段。使用支持目录授权的独立桌面浏览器时，可以把实际 Vault 作为授权根目录并选择真实写入。只有确认写入后的真实回执才意味着文件已写到该目录。本轮浏览器回归覆盖了演示及私有文件系统写入，真实 Vault 仍需在你自己的浏览器中授权验收。

### Local Workspace

**案例**。在保存抽屉选择 Local Workspace，输入相对子目录 `CiteWeave/Research` 并选择 Markdown。需要演练时直接预览并确认模拟保存。需要实际文件时，在桌面 Edge 或 Chrome 中点「授权实际目录」，建议选择一个空的测试文件夹，然后检查路径与内容，再确认真实写入。

**覆盖和权限边界**。目录访问由浏览器授权，文件路径限制在授权根目录内。请填写相对路径，`..` 和盘符路径会被拒绝。已存在的目标会显示更新预览，文件在预览之后发生变化时会提示重新检查。刷新后可以用原来的演示设置，实际目录需要重新授权。若浏览器或嵌入预览无法选择目录，改用独立浏览器或下载。真实目录可写入支持的非 PDF 格式，PDF 通过打印或模拟保存体验。

**查看回执**。打开「外部集成 → 保存历史」，点记录查看路径、内容和时间。使用「断开」结束当前授权或关闭模拟配置。之前的回执仍可查阅。

## 12. 设置、备份与常见问题

- **个性化**。可改显示名称、浅色或深色主题、默认保存目的地。点「保存设置」后应用。默认目的地用于预选保存面板。
- **模型与 API**。演示模型名称和 API 地址用于试用设置界面。这里不发出模型请求，请使用示例地址，避免输入真实凭据。
- **工作区数据**。「下载工作区数据」导出当前浏览器的 JSON 快照，可留作核对和备份。当前提供导出，恢复导入界面尚未提供。
- **刷新后找不到成果**。先检查是否还有同一浏览器配置、端口和 `/prototype.html` 路径，再核对浏览器站点存储。
- **搜索或筛选没有结果**。清除筛选，输入更短的词。Agent 只显示已完成的资料，请到任务中心确认状态。
- **预览显示演示故障**。在任务中心点重新执行。Bilibili 分 P 缺字幕时，用补充字幕或模拟 ASR 继续原任务。
- **无法下载或写入文件**。先检查浏览器下载权限和目录授权。可用下载时优先确认文件名，再通过本机文件管理器检查结果。
- **端口被占用**。关闭你自己启动的旧实例，或使用 `npm.cmd run dev -- --port 5178`。换端口会使用独立工作区数据。

## 13. 对照完整项目的覆盖情况

| 层次 | 当前交付 | 后续产品能力 |
| --- | --- | --- |
| 用户旅程 | 工作台、导入、任务、资料与分类、研究、编辑、保存、导出 | 按你的验收反馈决定正式版本保留的交互 |
| 资料摄取 | 模拟链接和内容处理，真实文件选择与基本校验 | 真实 Bilibili 短链与字幕、视频存储、FFmpeg/ASR、网页和仓库正文解析 |
| AI 与证据 | 演示摘要、问答、工具步骤和片段定位 | 真实 LLM、检索与引用校验、跨资料分析、可恢复 Agent |
| 工程与交付 | 当前浏览器持久化、文件导出和有条件的目录授权 | 服务端业务数据、多设备和权限、任务可靠性、监控与故障恢复 |
| 外部目的地 | 模拟提交与保存回执、浏览器下载 | GitHub OAuth 与真实提交、跨环境 Vault 授权体验及正式部署 |

建议先用原型确认每个目标用户最常走的路径。正式开发应先接「真实导入 → 可追溯定位 → 保存成果」，再根据使用反馈决定扩大内容类型还是增强 Agent。
